# AirFace Color System

## Direction

AirFace uses a premium aviation-intelligence visual language: an obsidian aircraft cabin, warm cockpit instrumentation, and statistical research terminal. The interface is intentionally charcoal-led, with copper for emphasis and muted teal for healthy system flow.

## Core Palette

| Role | Hex | Usage |
|---|---|---|
| Obsidian | `#0D0F0E` | Primary page background |
| Secondary charcoal | `#151817` | Navigation and secondary surfaces |
| Elevated surface | `#1C211F` | Data panels and repeated items |
| Warm surface | `#242621` | Highlighted panels and controls |
| Warm ivory | `#F3EFE5` | Primary text and key data |
| Secondary ivory | `#B7B5AC` | Supporting text |
| Muted gray | `#7F817B` | Labels and low-priority metadata |
| Copper / aviation brass | `#D68A3A` | Primary action, active state, index emphasis, chart highlights |
| Muted aviation teal | `#4FA89A` | Healthy pipeline state and secondary series |

## Status Palette

- Success: `#5FAF82`
- Warning: `#D6A14A`
- Error: `#C96B5B`
- Info: `#9BA7A0`

## Application Rules

- Copper is reserved for decisions, active navigation, important markers, and primary actions.
- Teal is used sparingly for healthy operations and positive data flow.
- Charts use warm ivory for the primary series, copper for highlights, muted teal for secondary data, and muted gray for references.
- Panels use thin warm-gray borders and restrained 8-14px radii. Glass treatment is limited to navigation and surfaces that need depth.
- Synthetic/demo validation is labeled separately from external or official data.
- Blue and electric cyan are not part of the active product identity.
