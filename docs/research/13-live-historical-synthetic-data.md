# Data Provenance & Multi-Mode Data Architecture

---

## 1. Strict Data Mode Partitioning & Isolation

To maintain 100% scientific integrity and prevent misleading SIH evaluation judges, the system implements **strict structural isolation** across three operational data modes:

```
                      [ Data Ingestion Router ]
                                  │
         ┌────────────────────────┼────────────────────────┐
         ▼                        ▼                        ▼
  [ MODE: LIVE ]          [ MODE: HISTORICAL ]     [ MODE: SYNTHETIC ]
  Scraped from live       Archived from past       Generated by model
  web pages in real time  30-day collection runs   calibrated to real data
```

### Data Mode Definitions & Compliance Rules

| Data Mode | Definition | Primary Purpose | Mandatory UI Badge | Restrictions |
|---|---|---|---|---|
| **`LIVE`** | Raw or cleaned fare records extracted from live target websites in real-time | Real-time index production | `[LIVE DATA]` (Green) | Subject to network availability & target rate limits |
| **`HISTORICAL`** | Verified scraped observations collected and stored during past operating windows | 30-day backtesting & time-series analysis | `[HISTORICAL DATA]` (Blue) | Must retain original collection timestamps |
| **`SYNTHETIC`** | Programmatically generated fare records calibrated to real historical price distributions | Demonstration stability & load testing | `[SYNTHETIC MOCK]` (Amber Alert) | **NEVER PRESENTED AS LIVE DATA TO JUDGES** |

---

## 2. Ethical Rules Regarding Synthetic Data

> [!CAUTION]
> **JUDGING ETHICS GUARANTEE:**  
> Representing synthetic or simulated data as "live scraped data" to SIH judges constitutes immediate disqualification. The dashboard UI and API responses MUST explicitly badge all synthetic outputs with a prominent warning label `[MODE: SYNTHETIC]`.

## 3. Data Provenance & Cryptographic Audit Trail

Every observation record stores an explicit provenance metadata block:

```json
{
  "observation_id": "8f3b2a1c-4d5e-6f7a-8b9c-0d1e2f3a4b5c",
  "provenance": {
    "collection_mode": "LIVE",
    "source_portal": "MakeMyTrip",
    "source_url": "https://www.makemytrip.com/flight/search?itinerary=DEL-BOM-01/10/2026",
    "parser_version": "v1.4.2",
    "http_status_code": 200,
    "payload_sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
  }
}
```

This provenance block allows NSO statisticians to inspect the exact HTTP payload hash and source URL for any single price quote in the index.
